Instrucciones

  • Para avanzar, presiona D o para caminar. Para correr, mantén presionada la tecla Shift junto con la tecla para caminar
  • Para saltar, presiona la barra espaciadora, W o ↑
  • Los perros provocan que pierdas 100 puntos y una vida, ¡Cuidado!
  • Tienes 3 vidas, si pierdes todas, perderás el juego

Algunos consejos:

  • Para un mejor salto, debes estar corriendo antes de saltar
  • Después de saltar, si quieres continuar corriendo, necesitas presionar las teclas nuevamente
  • Presta atencion a los enemigos y las diferentes plataformas de juego. ¡Los premios aparecen por todos lados!
